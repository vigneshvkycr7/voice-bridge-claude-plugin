# voice-bridge

A Claude Code plugin marketplace containing one plugin: **voice-bridge**, a
[Channel](https://code.claude.com/docs/en/channels) that bridges a remote
voice/text client (a phone app, a webhook, anything) into a live Claude Code
session.

See [`voice-bridge/README.md`](voice-bridge/README.md) for setup,
configuration, and the current experimental-status caveats.

## Quick start

```
/plugin marketplace add <this-repo's-git-url-or-local-path>
/plugin install voice-bridge@voice-bridge-marketplace
```

Then follow [`voice-bridge/README.md`](voice-bridge/README.md) to configure
and run it.
